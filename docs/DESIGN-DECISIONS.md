# 설계 결정 (ADR 요약)

왜 이렇게 만들었는지에 대한 짧은 기록입니다. 각 항목은 *맥락 → 결정 → 결과* 순서입니다.

## 1. 설정을 코드가 아니라 데이터로 (2계층 상속)

- **맥락**: 브랜드/테넌트가 늘 때마다 코드를 고치고 배포하는 구조는 확장 비용이 선형으로 증가한다.
- **결정**: 변하는 것(주기·파라미터)은 `TenantOverride` 로 내리고, 변하지 않는 실행 규칙은
  `JobDefinition` 상위 계층에 둔다. 오버라이드는 **필드 단위 nullable** 로 상속을 표현한다.
- **결과**: 새 테넌트 투입이 행 추가로 끝난다. 병합 로직은 한 함수에 모여 테스트가 쉽다.
  ([ConfigResolverTests](../tests/FlowForge.Tests/ConfigResolverTests.cs))

## 2. 공통 관심사를 상속이 아니라 Behavior 파이프라인으로

- **맥락**: 로깅·재시도·타임아웃·멱등성을 각 잡이 상속으로 물려받으면, 순서·조합을 바꾸기 어렵고
  깊은 상속 트리가 생긴다.
- **결정**: 관심사를 각각 `IJobBehavior` 로 분리하고 `Order` 로 합성한다(미들웨어 방식).
  잡의 고유 로직은 `JobBase.ExecuteCoreAsync` 하나로 남긴다.
- **결과**: 관심사 추가/재배치가 등록 한 줄. Retry가 Timeout을 감싸 "시도별 타임아웃"이 자연스럽게 성립한다.

## 3. 팬아웃을 등록이 아니라 발사 시점에

- **맥락**: 테넌트마다 스케줄을 등록하면 등록 수가 `도메인 × 테넌트` 로 폭증한다.
- **결정**: 스케줄은 도메인 단위로만 등록하고, Cron 도래 시 `ResolveAll` 로 테넌트에 팬아웃한다.
- **결과**: 등록 비용은 도메인 수로 유지. 테넌트 300개여도 스케줄 엔트리는 도메인 수만큼.

## 4. 도메인 발견을 Attribute + 리플렉션으로

- **맥락**: 중앙 등록 목록(switch/딕셔너리)은 도메인이 늘수록 병목이자 머지 충돌 지점이 된다.
- **결정**: `[JobHandler("key")]` 를 스캔해 자동 등록한다. 잘못된 부착(추상/미구현)은 시작 시 예외로 막는다.
- **결과**: 새 도메인 = 클래스 + Attribute. 배선 코드를 건드리지 않는다.

## 5. 인메모리를 기본값으로, 인프라는 어댑터로

- **맥락**: 포트폴리오/데모가 브로커·DB 설치를 요구하면 아무도 돌려보지 않는다. 반대로
  인프라에 강결합하면 버전 문제로 빌드조차 안 되기 쉽다.
- **결정**: 모든 인프라(버스·스토어·락)를 인터페이스로 추상화하고 **인메모리 구현을 기본**으로 제공한다.
  RabbitMQ/Redis/Postgres는 같은 인터페이스의 어댑터로 문서화한다.
- **결과**: `dotnet run` 하나로 전 기능이 동작한다. 프로덕션 전환은 DI 등록 교체.
  설계 역량(패턴)과 실행 가능성(데모)을 동시에 보여준다.

## 6. 운영 제어를 개발자가 아니라 운영자에게

- **맥락**: 스케줄러를 멈춰야 하는 상황은 (1) 외부 점검 전면 중단, (2) 특정 테넌트 부분 배제,
  (3) 신규 도메인 시범 가동으로 나뉜다. 매번 개발자가 개입하면 대응이 느리다.
- **결정**: 세 상황에 각각 대응하는 **전역 일시정지 · 도메인/테넌트 차단 · 검증(dry-run) 모드**를
  게이트로 만들고 API로 노출한다. 게이트는 파이프라인 안에서 매 실행 직전 평가된다.
- **결과**: 운영자가 배포 없이 즉시 대응한다. 검증 모드는 부작용 없이 신규 도메인을 프로덕션에서 확인한다.

## 7. 실패를 예외가 아니라 결과와 보상으로

- **맥락**: 한 트랜잭션으로 못 묶는 다중 시스템 처리에서, 중간 실패는 데이터 불일치를 남긴다.
- **결정**: 대량 처리는 아이템 실패를 스텝 결과로 **격리·집계**하고, 다중 시스템 처리는 Saga로
  **완료 스텝을 역보상**한다. 보상 실패는 별도 상태로 보고해 수동 개입 지점을 남긴다.
- **결과**: 부분 실패에도 배치가 진행되고, 시스템 간 정합성이 보상으로 회복된다.
  ([SagaRunnerTests](../tests/FlowForge.Tests/SagaRunnerTests.cs))

## 범위에서 의도적으로 제외한 것

- **실제 브로커/DB 어댑터 구현** — 인터페이스와 compose 프로파일까지만. 패턴 전달이 목적이므로.
- **인증/멀티테넌시 보안** — 컨트롤 플레인은 데모용으로 무인증. 프로덕션은 JWT + YARP 게이트웨이 전제.
- **영속성** — 인메모리 스토어는 프로세스 재시작 시 초기화된다(설계상 명시적 선택).
